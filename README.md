# field-agent

An engagement agent that walks the mall for you: it scrapes promotions from a shopping-center portal, enriches them with brand data, verifies they still match the source, and serves them through a typed API and a UI.

> Take-home for Engagement Agents: "Promotions Aggregator (Single-Mall MVP)". Target portal: [The Promenade Shops at Briargate](https://www.thepromenadeshopsatbriargate.com/sales/).

Start with [DESIGN.md](./DESIGN.md) for the decisions and [ASSUMPTIONS.md](./ASSUMPTIONS.md) for interpretations of the brief.

_Quick start, API walkthrough, environment variables, tests, and known limitations are filled in as the build lands._
